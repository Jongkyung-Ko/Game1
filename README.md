# 풍요의 마을 · 좀비석

Kotlin + Jetpack Compose 로 만든 안드로이드 모바일 RPG 초안입니다.
마을 지도와 캐릭터를 이미지 리소스 없이 **Canvas 로 직접 그려서**, 별도 이미지 에셋 없이 바로 실행됩니다.

## 시나리오

마을은 과거 **신성한 포도주**로 거대한 부를 누리던 곳이었습니다.
그러나 던전 최하층에서 검붉은 **좀비석(Zombie Stone)** 이 발굴되고, 영주와 연금술사들이 그 마력으로 병을 고치고 목숨을 늘리려다 저주를 불러옵니다.
오염된 사람들은 죽지도 못한 채 뇌가 부패하여 생살 허기만 남은 좀비가 되었고, 지하 보관소와 하수도는 **좀비의 둥지(던전)** 가 되어 지상까지 위협합니다.

## 마을에 배치된 장소 (12곳)

| 장소 | 할 수 있는 일 |
|------|---------------|
| 주인공 집 | 잠자기(무료·완전 회복), 회복 아이템 사용 |
| 상점 | 횃불·붕대·소모품·장신구 구매/판매 |
| 무기점 | 좀비 대비 무기·방패·갑옷·투구 구매 |
| 병원 | 오염 상처 치료, 해독 영양제 |
| 교회 | 저주 정화 기도, 헌금(3일간 축복) |
| INN | 숙박, 좀비석·영주 관련 소문 |
| PUB | 선술집 안을 걸어 다니며 NPC와 시나리오 대화 |
| 대련소 | 지하 진입 전 대련으로 경험치·상금 |
| 던전입구 | **라그나로크식 도보 탐험** — 미로를 걸어다니며 좀비와 조우 |
| 대장간 | 착용 장비 강화 |
| 마법학교 | 해독·정화 마법 습득, 고서 연구 |
| 용병고용소 | 좀비 사냥 용병 고용 / 원정대 편성 |

## 던전 (라그나로크식)

- 층을 직접 걸어 다니며 탐험합니다 (카메라가 주인공을 따라감).
- 화면을 탭하면 그 지점으로 이동하고, 좀비를 탭하거나 접촉하면 전투합니다.
- 하수도·보관소 타일과 미니맵, 출구(↑)·심층(↓) 계단이 있습니다.
- 심층 계단에서 `내려가기`, 출구에서 `탈출`할 수 있습니다.

## 조작

- **건물을 탭** → 길을 따라 그 앞까지 걸어간 뒤 자동 입장
- **빈 땅을 탭** → 마을 대로를 경유해 그 지점으로 이동
- **PUB/던전의 대상 탭** → 다가간 뒤 대화 또는 전투
- 뒤로 가기 → 메뉴 닫기 / 마을로 나가기 (던전에선 탈출)

## 음악과 효과음

- 마을 / 아늑한 실내 / 던전·대련소 BGM이 전환됩니다.
- 걸을 때 발소리, 전투·문 개폐 시 효과음이 재생됩니다.
- 음원은 무료 개발자용 MP3 (`res/raw`)이며, 라이선스는 `app/src/main/assets/AUDIO_CREDITS.txt` 를 참고하세요.

## 실행 방법

1. [Android Studio](https://developer.android.com/studio) (Ladybug 이상 권장) 설치
2. `File > Open` 으로 이 폴더를 엽니다
3. Gradle Sync가 끝나면 (SDK·Gradle 자동 다운로드) 상단 `Run ▶` 실행

```bash
./gradlew assembleDebug
```

> `gradle/wrapper/gradle-wrapper.jar` 는 저장소에 포함되어 있지 않습니다.
> Android Studio가 첫 Sync 때 생성하며, 직접 만들려면 `gradle wrapper` 를 한 번 실행하세요.
